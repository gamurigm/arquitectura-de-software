# Servidores de aplicaciones Java GR09

- En los proyectos GR09 de esta carpeta, usa exclusivamente Payara Server Community 7 cuando se requiera un servidor de aplicaciones Java.
- Configura `PAYARA_HOME` con la carpeta principal `payara7` y ejecuta `bin/asadmin.bat` desde ella.
- Conserva la estructura interna de la distribución oficial de Payara.
