API REST - Conversion de Unidades Monster

Servidor Spring Boot compilado con JDK 25 (bytecode compatible con Java 21), sin base de datos. Grupo 10 - NRC 36884.

Documentacion OpenAPI (Swagger UI)

Endpoint de seguridad

MetodoRutaDescripcion
POST/api/auth/loginLogin (usuario: Monster / clave: Monster9). Devuelve token.
POST/api/auth/logoutRevoca el token (requiere Authorization).

Endpoint de obtenerCatalogo (publico)

GET /api/catalogo

Endpoints de conversion (requieren token)

MetodoRutaUnidades
POST/api/conversiones/longitudcentimetros, metros, pies, yardas, millas
POST/api/conversiones/masagramos, kilogramos, onzas, libras, quintales
POST/api/conversiones/temperaturafahrenheit, kelvin, celsius, newton, reaumur

Ejemplo

curl -X POST http://localhost:8080/api/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"usuario\":\"Monster\",\"clave\":\"Monster9\"}"

curl -X POST http://localhost:8080/api/conversiones/longitud ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer <TOKEN>" ^
  -d "{\"valor\":10,\"unidadOrigen\":\"metros\",\"unidadDestino\":\"pies\"}"
