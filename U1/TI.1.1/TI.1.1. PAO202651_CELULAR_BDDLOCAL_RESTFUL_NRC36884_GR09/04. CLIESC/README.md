# Cliente escritorio WPF

Consume la API de la comercializadora y permite catálogo, ventas y consultas. Para requisitos y ejecución, consulte `../05. DOCUMENTACION/ManualTecnico.md`.

La vista nativa está en `MainWindow.xaml`; la coordinación se encuentra en `Controladores/ControladorEscritorio.cs` y el transporte compartido en `00. COMPARTIDO/Celulares.Cliente/Servicios`.
