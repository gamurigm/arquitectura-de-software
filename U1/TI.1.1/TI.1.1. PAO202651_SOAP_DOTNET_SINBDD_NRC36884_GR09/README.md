# Conversor de Unidades Monster GR09 — SOAP .NET

Proyecto sin base de datos: servidor CoreWCF y cuatro clientes MVC.

- `01. UML`: ERS, casos de uso y diagramas.
- `02. MER` y `03. BDD`: estructura conservada; no aplican al alcance sin base de datos.
- `04. SERVIDOR`: servicio SOAP.
- `04. CLICON`: cliente de consola .NET 10.
- `04. CLIESC`: cliente WPF .NET 10.
- `04. CLIWEB`: cliente ASP.NET Core MVC .NET 10.
- `04. CLIMOV`: cliente Android .NET MAUI.
- `05. DOCUMENTACION`: manual técnico del servidor y sus cuatro clientes.
- `02. MER` y `03. BDD`: estructura conservada; no contienen modelos ni esquemas porque el proyecto es SINBDD.

Los artefactos .NET se generan bajo `D:\tools\GR09-SOAP-DotNet\artifacts` y los paquetes NuGet bajo `D:\tools\nuget-packages`.
