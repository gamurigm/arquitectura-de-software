# Servidor REST

API ASP.NET Core 10 con controladores, servicios y modelos. Escucha en http://127.0.0.1:19082.

Desde la raíz del proyecto, inicia el servidor con:

~~~powershell
. .\ConfigurarEntornoDotNet.ps1
.\04. SERVIDOR\IniciarServidor.ps1
~~~

No cierres esta terminal durante las pruebas. Contrato OpenAPI: /openapi/v1.json.
