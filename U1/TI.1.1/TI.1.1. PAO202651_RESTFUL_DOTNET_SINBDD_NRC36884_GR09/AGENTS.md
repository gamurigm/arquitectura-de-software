# Instrucciones REST .NET GR09

- Conserva carpetas numeradas y nombres existentes del proyecto.
- Mantén código, mensajes y documentación en español; conserva nombres requeridos por .NET, HTTP y JSON.
- El servidor usa controladores, servicios, modelos y middleware. No agrega persistencia.
- Cada cliente separa modelo, vista, controlador y servicio. Consola, WPF y MAUI usan carpetas españolas; la web conserva Controllers, Models, Views y Services de ASP.NET Core MVC.
- Conserva el contrato REST: credenciales monster / monster9, token de 10 minutos, rutas /api/* y JSON camelCase.
- Consulta el ERS y este contrato antes de cambiar operaciones, unidades o formatos.
- Usa .NET 10 y C# 14. Redirige paquetes, temporales y compilación a D:\tools.
- No alteres otros proyectos ni sus artefactos.
