# Carpeta de Imágenes

Esta carpeta contiene los recursos de imagen del proyecto.

## Logo

El archivo `logo.png` debe ser copiado desde el proyecto RESTFUL:
- Origen: `CONUNI_RESTFUL_DOTNET_CLIWEB_G09/wwwroot/images/logo.png`
- Destino: Esta carpeta (`wwwroot/images/logo.png`)

El logo se muestra en la página de login.
