# 📁 Carpeta Resources - Logo del Login

## 📍 ¿Dónde poner el logo?

**Coloca tu archivo de imagen del logo aquí en esta carpeta con el nombre:**

```
logo.png
```

## 📋 Instrucciones:

1. **Nombre del archivo**: El archivo debe llamarse exactamente `logo.png`
2. **Ubicación**: Coloca el archivo `logo.png` directamente en esta carpeta `Resources/`
3. **Formato**: El archivo debe ser una imagen PNG (recomendado) o JPG
4. **Tamaño recomendado**: 200x200 píxeles o más (el código lo redimensionará automáticamente)

## ✅ ¿Qué hace el código?

El código de `VentanaLogin.cs` buscará automáticamente el logo en esta ubicación y lo mostrará en el panel izquierdo del formulario de login.

## 🔄 Después de agregar el logo:

1. **Compila el proyecto** (Build → Build Solution)
2. **Ejecuta la aplicación** y verás el logo en la ventana de login

## 📂 Estructura esperada:

```
CONUNI_SOAP_DOTNET_CLIESC_G09/
  └── Resources/
      └── logo.png  ← **PON TU LOGO AQUÍ**
```

---

**Nota**: Si no encuentras el logo, el sistema mostrará temporalmente el texto "LOGO" hasta que agregues el archivo.
